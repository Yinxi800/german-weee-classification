# 德国 WEEE 分类初筛

静态网页：优先匹配本地维护、逐条核对的 EAR 产品词条。可直接匹配时显示带适用条件的初筛建议；候选类型不唯一时只询问关键条件。未匹配 EAR 条目的产品转人工复核。支持复制与导出 JSON；产品信息在浏览器本地处理。

## EAR 目录接口

`data/ear-product-catalog.js` 是 2026-10-29 从 EAR 官网通过有限关键词查询获取的 **284 条不同搜索结果（278 个德语产品名称）**，保留官方德语/英语名称、候选类型、备注及查询词。搜索词为 a、e、i、o、u、b、Router、Leuchte、Kühlschrank；空词与通配符未获得整库，因此它是部分搜索结果，不是完整数据库。`data/ear-products.js` 为此前逐条核对的少量样例，`data/ear-catalog-aliases.js` 为自行维护的中文精确别名。`data/ear-catalog-zh.js` 包含这 278 个不同德语产品名称的机器翻译及部分术语人工修订（包含 284 条中的同名条目）；译名不是 EAR 官方中文名称，存在歧义时保留原文并转人工核对。中文别名及判定逻辑均非 EAR 原文。

项目另行调用 EAR **生产环境** `VerzeichnisService.getAlleGeraetearten`，将设备类型目录快照保存在 `data/ear-directory.js`，用于核对候选设备类型名称。网页结果不展示设备类型编号。

EAR 返回包括历史类型的完整目录，并非全部都是现行注册选项。页面只使用已核对的候选类型映射；官方分类规则或目录有变化时，需要重新审核代码映射。

这些文件均为**本地快照**，每次访问网页不会直接请求 EAR。GitHub Pages 是静态托管，现有 SOAP 方法返回设备类型目录，不提供按产品名称查询。EAR 官网的产品搜索表单能查询产品，但目前未找到该产品库的官方公开 API 或完整下载入口，EAR 的网站声明允许为自身直接的私人或职业目的保存和复制文本等内容，并禁止向第三方有偿转交内容；批量获取、对外公开、自动化请求及具体复用范围仍应向 EAR 确认。参见 [EAR 网站声明](https://www.stiftung-ear.de/impressum/)。正式使用前请在 [EAR 官方工具](https://www.stiftung-ear.de/service/geraetezuordnung/)核对。

本机更新快照，在项目目录执行：

```sh
python3 scripts/sync_ear.py
```

该脚本使用 Python 标准库发送 SOAP 1.1 请求，解析 EAR 返回的 multipart/MTOM 或 XML。若请求、解析或验证失败，保留原有快照并报告失败。上面的命令只更新本地文件，上传仓库后网页才会更新。

## 部署到 GitHub Pages

**访问权限：**仓库设为私有并不代表 GitHub Pages 网站也私有。GitHub 个人账号的 Pages 网站可能向互联网公开；私密 Pages 访问控制需满足 GitHub Enterprise Cloud 的组织条件。上线前先确认网站访问权限及 EAR 数据复用范围。

1. 在 GitHub 新建仓库，将本目录中的 `index.html`、`style.css`、`app.js`、`data/`、`scripts/` 和本文件放在仓库根目录并推送。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择包含这些文件的分支和 `/ (root)`，保存。
3. 等待 Pages 构建完成，打开设置页显示的网址。使用相对路径，支持项目仓库的子路径。

无需安装依赖或构建；直接打开 `index.html` 也可使用。部分浏览器可能限制本地文件的剪贴板访问，可使用 JSON 导出。

## 使用边界

- 精确匹配本地词库中的德语、英语名称和 278 条非官方中文译名，并有少量人工维护的中文别名；提供名称建议但不对自由输入使用 AI 推断。单一候选且备注未表明额外条件的条目给出初筛建议及假设，常见尺寸/用途歧义会提问；其他特殊备注、未匹配或同名冲突进入人工复核，保留官方原文。
- 分类参照 EAR 公开判断流程，是初筛而非官方决定，不核查注册主体、品牌或已有注册。
- 产品范围、排除情形、组件与套装等需结合实际资料复核。
- SOAP 目录方法返回系统中的设备类型、关联类别等，并非按商品名称判类。[EAR 接口说明](https://ear-system.de/ear-soap/v2/doc/service_ear_VerzeichnisService.html)。
- 规则核对日期：2026-10-29。法规及官方流程可能更新，正式使用前应重新审核。

## 用户提供的分类参考

`data/user-examples.js` 仅保留从用户资料提取的 375 个不同产品名称及资料中的参考类别；不含 Excel 或 PDF 原件及资料原文。桌面原件未修改。参考类别仅用于对照，未匹配 EAR 或存在歧义时转人工复核。

已对照 EAR 公开产品搜索的 284 条现有快照；现有快照只是有限关键词搜索结果，并不覆盖所有产品。具体查询及差异见 `来源冲突与复核.md`。
